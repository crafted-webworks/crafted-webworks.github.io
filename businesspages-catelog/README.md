## 📱 How to Add Items to WhatsApp Business Catalog

1. Open **WhatsApp Business** on your mobile
2. Go to **Settings → Business Tools → Catalog → Add New Item**
3. Upload `preview.jpg` from the item folder as the product image
4. Copy text from `catalog-details.txt` → paste Name, Price (in ₹) and Description
5. Save → repeat for all 10 items!
